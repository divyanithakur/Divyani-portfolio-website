# Divyani Gour Portfolio

A lightweight portfolio built with HTML, CSS, and vanilla JavaScript.

## Run locally
Open `index.html` in a browser, or use VS Code Live Server. No npm install, database, or API keys are needed.

## Files
- `index.html` — content and project/contact links
- `css/style.css` — responsive layout and black/white/gold theme
- `js/main.js` — mobile navigation, theme toggle, copy-email action, and current year
- `assets/images/divyani.jpg` — profile photo
- `assets/resume/Divyani-Gour-Data-Analyst-Resume.pdf` — downloadable resume

## Functional details
- Navigation scrolls to page sections and collapses on mobile.
- Theme toggle switches between the original dark gold palette and a light variant.
- Resume download uses the included PDF.
- ProcureIQ, Kairos, and EcoPulse AI cards link to their live project websites.
- Email, phone, GitHub, and LinkedIn links are clickable.
- The email-copy button uses the clipboard when browser permissions allow, with an email-app fallback.


## Design approach
The portfolio uses a restrained black/white/gold palette, a simpler portrait hero, clear experience and project sections, grouped skills, achievements, and prominent contact/resume links. This follows common portfolio guidance to explain project context, show a working demo or source link, keep skills scannable, and make the resume easy to reach. No performance metrics or business outcomes have been invented.
